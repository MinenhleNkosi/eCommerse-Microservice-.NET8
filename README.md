# eCommerse-Microservice-.NET8
Building a .NET 8 eCommerce application using microservices with API Gateway, Rate Limiting, Caching, and more.

This project demonstrates an eCommerce microservice architecture with an API Gateway. It includes independent services for handling specific business functions such as products, orders, and user accounts. The API Gateway serves as a single entry point for client requests, providing functionalities like rate limiting, caching, and routing to the appropriate microservice.

<details>
<summary><strong>Features</strong></summary>
	
1. **Microservices:** Independent services for different business functions.
2. **API Gateway:** Centralized entry point for handling requests.
3. **Rate Limiting:** Controls the rate of incoming requests.
4. **Caching:** Stores frequently accessed data to improve performance.
5. **.NET 8:** Leverages the latest features of .NET 8.
</details>
